# Ticket Counter Live

estamos dos personas llevando la cuenta de las entradas que vendemos para una fiesta y quiero una app muy muy simple, que se trate de un contador para llevar la cuenta de las entradas que se han vendido, las personas que van a la fiesta, el dinero recaudado y el numero de entradas restantes, ademas queremos que para nosotros, podamos ver el listado de personas a las que cada uno ha vendido la entrada, además quiero que sea en movil y que este conectada en tiempo real, tengo un excel con lo que hacemos, pero lo quiero para tenerlo los dos en el movil
